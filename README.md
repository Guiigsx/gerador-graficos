# Estudio de Graficos

Editor visual para criar graficos de barras, barras horizontais, linhas, pizza e rosca diretamente no navegador. A previa acompanha cada alteracao e o resultado pode ser baixado em PNG.

**Acesse o site:** [gerador-graficos.vercel.app](https://gerador-graficos.vercel.app)

## Recursos

- Edicao de dados, titulos, legendas, fontes e cores em tempo real.
- Linhas de media e referencia configuraveis.
- Posicionamento automatico dos valores para evitar sobreposicoes.
- Diferentes proporcoes de imagem e exportacao em PNG.
- Interface responsiva para computador e celular.

## Executar localmente

Requer Node.js 18 ou mais recente.

```bash
npm start
```

Abra [http://localhost:4173](http://localhost:4173).

## Testes

```bash
npm test
```

Os testes validam o posicionamento dos rotulos em cenarios com linhas e legendas de referencia.
